# sns-media

**あわじのきのこや_奥田製作所** のSNS自動投稿システムが使う、素材の一時置き場です。

## なぜこのリポジトリが公開なのか

Instagram と Facebook は、ファイルを直接受け取る仕組みを持っていません。
「このURLに画像があるので取りに来てください」という方式しかないため、
投稿する画像は一度インターネット上の公開URLに置く必要があります。

つまりこの公開設定は、**Instagramに投稿するための技術的な要件**です。

- ここに置かれるのは、**これから投稿する(または投稿した)写真**だけです
- ボツにした素材は、システムが自動的に削除します
- **プログラム本体と、まだ投稿していない下書きの文章は、別の非公開リポジトリにあります**

## 中身

    media/YYYY/MM/<ランダムな名前>.jpg

ファイル名をランダムにしているのは、連番だと第三者に一覧されやすいためです。
